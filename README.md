# Tanuki Viewer KR

로컬의 **타누키 스타터 키트**를 브라우저에서 탐색하는 Windows용 로컬 뷰어입니다. 스타터 키트 이미지 자체는 이 저장소에 포함하지 않습니다.

## 실행

1. 배포 ZIP을 한 번만 압축 해제합니다.
2. `START_Tanuki_Viewer.bat`를 실행합니다.
3. 브라우저에서 **스타터 키트 열기**를 눌러 로컬 폴더를 선택합니다.

`index.html` 직접 실행도 가능하지만 GitHub 자동 업데이트는 로컬 런처를 통해 실행했을 때만 동작합니다.

## 업데이트 방식

`update-manifest.json`에 배포 대상 파일과 SHA-256을 기록합니다. 설치된 Viewer는 GitHub `main` 브랜치의 manifest를 확인하고, 새 버전이 있으면 파일을 임시 폴더로 다운로드한 뒤 해시 검증 후 교체합니다. 실패하면 기존 파일을 복원합니다.

업데이트 대상은 Viewer 프로그램 파일뿐입니다. 사용자가 선택하는 스타터 키트 원본은 수정·복사·업로드하지 않습니다.

## 새 버전 배포

1. 코드/카탈로그를 수정합니다.
2. `VERSION.json`의 버전을 올립니다.
3. `tools/Build-Manifest.ps1`을 실행합니다.
4. 생성된 `update-manifest.json`을 포함하여 `main`에 push합니다.

기존 이용자는 Viewer 상단의 업데이트 버튼만 누르면 됩니다.
