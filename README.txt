Tanuki Viewer KR v0.6.0 — Local Starter Kit + Auto Update Edition
==================================================================

[처음 실행]
1. 이 ZIP을 원하는 폴더에 한 번만 압축 해제합니다.
2. START_Tanuki_Viewer.bat를 더블클릭합니다.
3. 기본 브라우저에서 Tanuki Viewer KR가 열립니다.
4. [스타터 키트 열기]를 눌러 압축 해제한 "타누키 1차베이스" 최상위 폴더를 선택합니다.

중요: index.html을 직접 더블클릭해도 뷰어 자체는 동작하지만 자동 업데이트는 사용할 수 없습니다.
자동 업데이트가 필요하면 반드시 START_Tanuki_Viewer.bat로 실행하세요.

[자동 업데이트]
- 상단의 [업데이트 확인] 또는 [업데이트 vX.X.X] 버튼을 누릅니다.
- 새 버전이 있으면 GitHub에서 변경된 프로그램 파일만 내려받습니다.
- 스타터 키트 원본 GIF/PNG/WebP는 건드리지 않습니다.
- 다운로드가 끝나면 버튼이 [새로고침해 적용]으로 바뀝니다.
- 해당 버튼을 한 번 더 누르면 새 코드가 적용됩니다.
- 새로고침 후에는 브라우저 보안상 스타터 키트 폴더를 다시 선택해야 합니다.

[표시 이름]
- 각 캐릭터 소재는 원본 파일명 대신 #001, #002 ...처럼 자동 번호가 표시됩니다.
- [표시명 수정]으로 원하는 이름으로 바꿀 수 있습니다.
- 원본 파일명과 원본 상대 경로는 우측 "원본 정보"에 계속 보존됩니다.
- 사용자 표시명은 브라우저 localStorage에 저장되며 프로그램 업데이트 대상에 포함되지 않습니다.

[v0.6.0 주요 변경]
- 중앙 이미지가 정상 로드되어도 "조건에 맞는 소재가 없습니다" 오버레이가 남던 hidden/CSS 충돌 수정
- 761~1050px 화면에서 우측 필터·정보 패널을 열 수 있는 버튼 추가
- ^^ / ＾＾ 표정을 "미소"로 인식하도록 파서 보강
- 캐릭터별 소재 자동 번호 표시 + 사용자 표시명 수정
- GitHub 기반 원클릭 업데이트 구조 추가
- 다운로드 파일 SHA-256 검증 및 실패 시 롤백 처리

[개인정보/파일]
- 선택한 스타터 키트 이미지는 인터넷으로 업로드하지 않습니다.
- Viewer는 로컬 브라우저 세션에서 선택된 파일을 읽어 표시합니다.
- 자동 업데이트 시에는 프로그램 파일만 GitHub에서 내려받습니다.
